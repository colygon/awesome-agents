# SalesShortcut SDR - CrewAI Edition

## Overview
AI-powered Sales Development Representative system for outbound campaigns.

## Features
- Lead research and qualification
- Personalized outreach messaging
- Email copywriting
- Multi-touch sequences
- Objection handling
- Performance optimization

## Output
- Qualified lead profiles
- Personalization playbook
- Email template library
- Outreach sequence (6-8 touches)
- Objection handling guide
- Performance tracking framework

## Setup
```bash
pip install -r requirements.txt
cp .env.example .env
# Add OPENAI_API_KEY and optionally SERPER_API_KEY
python main.py
```

## Use Cases
- Building outbound SDR campaigns
- Creating email sequences
- Training new SDRs
- Optimizing response rates
