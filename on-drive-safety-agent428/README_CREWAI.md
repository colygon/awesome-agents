# ON:DRIVE Safety - CrewAI Implementation

Multi-agent vehicle safety platform for real-time monitoring, driver behavior analysis, risk assessment, and safety optimization.

## Agents

- **Vehicle Monitor**: System diagnostics, anomaly detection, health assessment
- **Driver Behavior Analyst**: Behavior analysis, safety scoring, coaching
- **Risk Assessor**: Road conditions, weather risks, safe routing
- **Safety Coordinator**: Integrated safety management and reporting

## Features

- Real-time vehicle system monitoring
- Driver behavior analysis and scoring
- Environmental risk assessment
- Personalized safety coaching
- Comprehensive safety reporting

## Installation

```bash
pip install -r requirements.txt
cp .env.example .env
```

## Usage

```bash
python main.py
```
