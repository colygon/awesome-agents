# Auto Insurance Agent - CrewAI Edition

## Overview
Virtual assistant for auto insurance company (Cymbal Auto Insurance).
Based on Google ADK sample, migrated to CrewAI.

## Features
- Member registration
- Claims processing
- Roadside assistance dispatch
- Rewards program

## Agents
1. **Membership Specialist** - Registers members
2. **Claims Handler** - Processes claims
3. **Roadside Coordinator** - Dispatches assistance
4. **Rewards Advisor** - Finds offers

## Migration from ADK
- **Original:** Google ADK with Gemini 2.5 Flash, Apigee API Hub
- **CrewAI:** OpenAI models, simulated API backends

**Version:** 1.0.0
