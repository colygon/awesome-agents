# News Aggregator - CrewAI Implementation

Multi-agent news aggregation system with collection, curation, fact-checking, and summarization capabilities.

## Agents
- News Collector: Gathers news from multiple sources
- Content Curator: Filters and organizes content
- Fact Checker: Verifies accuracy and credibility
- News Summarizer: Creates briefings and summaries

## Features
- Multi-source news aggregation
- Content filtering and categorization
- Fact-checking and bias detection
- News summarization and briefings
- Trending topic identification

## Usage
```bash
python main.py
```
