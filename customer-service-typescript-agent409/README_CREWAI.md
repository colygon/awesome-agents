# Customer Service (TypeScript) - CrewAI Edition

## Overview
AI customer service system with ticket analysis, knowledge base search, and response generation. Original ADK was TypeScript, this is Python CrewAI.

## Agents
- Ticket Intake Analyst
- Knowledge Base Specialist
- Response Composer
- Escalation Manager
- QA Specialist

## Installation
```bash
cd customer-service-typescript-agent409
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Usage
```bash
python main.py "I can't login to my account"
```
