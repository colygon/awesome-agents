# Language Tutor - CrewAI Implementation

Multi-agent language learning system with instruction, conversation practice, cultural education, and progress assessment.

## Agents
- Language Instructor: Grammar and vocabulary teaching
- Conversation Partner: Speaking practice and dialogue
- Cultural Guide: Idioms and cultural context
- Progress Assessor: Proficiency evaluation and study plans

## Features
- Structured language lessons
- Conversation practice
- Cultural context teaching
- Progress tracking and assessment

## Usage
```bash
python main.py
```
