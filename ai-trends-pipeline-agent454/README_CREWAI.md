# AI Trends Pipeline - CrewAI Edition

## Overview
Automated pipeline for monitoring, analyzing, and reporting on AI trends.

## Features
- Trend monitoring from multiple sources
- Data analysis and ranking
- Executive report generation

## Setup
```bash
cd ai-trends-pipeline-agent454
pip install -r requirements.txt
cp .env.example .env
# Add your OPENAI_API_KEY
python main.py
```

## Agents
1. **Trend Monitor** - Discovers emerging AI trends
2. **Data Analyst** - Analyzes growth and impact
3. **Report Generator** - Creates actionable reports

**Version:** 1.0.0
