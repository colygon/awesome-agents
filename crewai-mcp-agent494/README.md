# CrewAI-MCP - R Study Assistant

**Gallery ID:** 494
**Category:** CrewAI with Model Context Protocol
**Language:** Python

## Overview

CrewAI-MCP is an MCP-powered research assistant that combines CrewAI's multi-agent capabilities with the Model Context Protocol to create a comprehensive R study assistant. It features a beautiful Streamlit UI, integrates with Brave Search for web research, and uses Segmind API for AI image generation.

## External Repository

**Repository:** https://github.com/plaban1981/Crewai-MCP
**Author:** Plaban Nayak
**License:** Open Source

## Key Features

- **MCP Integration**: Leverages Model Context Protocol for enhanced agent communication
- **Multi-Agent System**: Research Agent + Writer Agent working collaboratively
- **Web Search**: Brave Search API integration for comprehensive research
- **AI Image Generation**: Segmind API for creating relevant visuals
- **Streamlit Interface**: Beautiful, user-friendly web interface
- **File Generation**: Produces search_results.json, summary.txt, and generated images
- **Multiple Tabs**: Summary, Search Results, and Generated Images views
- **Download Capabilities**: Download summaries and images as ZIP archives
