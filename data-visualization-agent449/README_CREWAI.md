# Data Visualization - CrewAI Implementation

## Overview
A multi-agent system for creating intelligent, beautiful, and insightful data visualizations and dashboards.

## Agents

### 1. Data Analysis Specialist
- Analyzes dataset structure
- Identifies patterns and trends
- Calculates statistics
- Detects anomalies

### 2. Visualization Design Expert
- Selects appropriate chart types
- Designs visual hierarchy
- Chooses color palettes
- Plans composition

### 3. Chart Generation Specialist
- Creates various chart types
- Applies formatting and styling
- Adds labels and annotations
- Ensures accuracy

### 4. Dashboard Architect
- Designs dashboard layouts
- Arranges visualizations
- Adds interactivity
- Ensures cohesion

### 5. Insight Analyst
- Extracts patterns from visuals
- Identifies key trends
- Formulates insights
- Communicates findings

## Setup

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Configure environment:
```bash
cp .env.example .env
# Edit .env with your preferences
```

3. Run the system:
```bash
python main.py
```
