# Incident Management - CrewAI Edition

## Overview
ServiceNow incident management system for IT support.
Based on Google ADK Application Integration sample.

## Features
- Incident creation
- Status tracking
- Resolution management
- Knowledge base integration

## Agents
1. **Incident Coordinator** - Creates and manages incidents
2. **Status Tracker** - Monitors progress
3. **Resolution Specialist** - Provides solutions

**Version:** 1.0.0
