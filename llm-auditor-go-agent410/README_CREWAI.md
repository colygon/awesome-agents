# LLM Auditor (Go) - CrewAI Edition

## Overview
Comprehensive LLM auditing system for evaluation, bias detection, safety assessment, performance analysis, and compliance. Original ADK was Go-based, this is Python CrewAI.

## Agents
- Model Evaluator - Benchmarks and metrics
- Bias Auditor - Fairness and bias detection
- Safety Evaluator - Toxicity and safety assessment
- Performance Analyzer - Technical performance metrics
- Compliance Auditor - Regulatory compliance
- Report Generator - Comprehensive audit reports

## Installation
```bash
cd llm-auditor-go-agent410
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Usage
```bash
python main.py "GPT-4" comprehensive
```

## Audit Dimensions
- **Quality**: Accuracy, coherence, task performance
- **Bias**: Fairness across demographics
- **Safety**: Toxicity, harmful content
- **Performance**: Latency, throughput, cost
- **Compliance**: GDPR, AI Act, governance
