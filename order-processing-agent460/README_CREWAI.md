# Order Processing - CrewAI Edition

## Overview
Automated order management system with human-in-the-loop approval.
Based on Google ADK Application Integration sample.

## Features
- Order validation
- Inventory management
- Payment processing
- Fulfillment coordination
- Human approval workflow

## Agents
1. **Order Validator** - Validates orders
2. **Inventory Manager** - Checks stock
3. **Payment Processor** - Processes payments
4. **Fulfillment Coordinator** - Manages shipping

## Migration from ADK
- **Original:** Google ADK with Application Integration Connectors
- **CrewAI:** OpenAI models, simulated backend systems

**Version:** 1.0.0
