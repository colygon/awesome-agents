# Travel Concierge Agent - CrewAI Edition

## Overview
AI-powered travel planning with destination research, flight/hotel booking, and itinerary creation.

## Installation
```bash
cd travel-concierge-agent406
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

## Usage
```bash
python main.py "Beach vacation for 2 weeks"
```
