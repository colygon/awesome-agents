# Real Estate Agent - CrewAI Implementation

Multi-agent real estate system for property search, market analysis, negotiation, and client guidance.

## Agents
- Property Finder: Search and match properties
- Market Analyst: Trends and valuation analysis
- Negotiation Specialist: Offer preparation and negotiation
- Client Advisor: Process guidance and education

## Features
- Property search and filtering
- Market trend analysis
- Property valuation
- Offer strategy and negotiation
- Client education and guidance

## Usage
```bash
python main.py
```
