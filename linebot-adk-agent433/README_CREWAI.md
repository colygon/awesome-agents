# LineBot ADK - CrewAI Implementation

Multi-agent LINE bot development system with conversation design, implementation, and UX optimization.

## Agents
1. **Conversation Designer** - Designs engaging conversation flows
2. **Bot Developer** - Implements LINE bot functionality
3. **UX Optimizer** - Enhances user experience and engagement

## Installation
```bash
pip install -r requirements.txt
cp .env.example .env
```

## Usage
```bash
python main.py
```

## Features
- Conversation flow design
- LINE Messaging API implementation
- Rich menus and Flex Messages
- UX optimization recommendations
