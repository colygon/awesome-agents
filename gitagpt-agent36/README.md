# Gita GPT - Agent 36 CrewAI Upgrade

A spiritual text analysis system powered by CrewAI, featuring multiple AI agents working together to provide deep insights from the Bhagavad Gita and other spiritual texts.

## Overview

This project uses CrewAI to orchestrate three specialized agents that work together to analyze spiritual texts, provide contextual insights, and offer practical guidance based on ancient wisdom.

## Agents

1. **Text Analyst Agent**: Analyzes and interprets spiritual texts
2. **Context Provider Agent**: Provides historical and philosophical context
3. **Practical Guide Agent**: Translates ancient wisdom into modern practical advice

## Installation

```bash
pip install -r requirements.txt
```

## Configuration

Create a `.env` file with your OpenAI API key:

```
OPENAI_API_KEY=your_api_key_here
```

## Usage

```bash
python main.py
```

Then ask questions about spiritual texts or life situations to receive insights from the three-agent crew.

## Features

- Multi-agent collaboration using CrewAI
- Deep analysis of spiritual texts
- Contextual understanding and interpretation
- Practical modern application of ancient wisdom
- Interactive question-answering system

## Requirements

- Python 3.8+
- OpenAI API key
- Dependencies listed in requirements.txt
