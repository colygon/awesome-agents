# Job Finder - CrewAI Edition

## Overview
AI-powered job search and application strategy system.

## Features
- Job search across multiple boards
- Resume-to-job matching
- Company research
- Application strategy

## Agents
1. **Job Researcher** - Finds opportunities
2. **Resume Matcher** - Calculates fit scores
3. **Application Strategist** - Plans applications

**Version:** 1.0.0
