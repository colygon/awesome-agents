# DA-Forge - CrewAI Implementation

Multi-agent data science platform for exploratory analysis, ML modeling, visualization, and solution delivery.

## Agents

- **Data Analyst**: EDA, pattern identification, statistical analysis
- **ML Engineer**: Model building, training, evaluation
- **Visualization Specialist**: Charts, dashboards, reports
- **Data Science Lead**: Project coordination and solution delivery

## Features

- Exploratory data analysis
- Machine learning modeling
- Interactive visualizations
- Comprehensive reporting
- Actionable recommendations

## Installation

```bash
pip install -r requirements.txt
cp .env.example .env
```

## Usage

```bash
python main.py
```
