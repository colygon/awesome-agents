# A2A ADK MCP - CrewAI Implementation

Multi-agent system for agent-to-agent communication with Model Context Protocol (MCP) integration.

## Agents
1. **Protocol Designer** - Designs communication protocols
2. **Message Coordinator** - Coordinates message routing
3. **Integration Specialist** - Integrates with MCP

## Usage
```bash
pip install -r requirements.txt
python main.py
```
