# Edu.AI Brazil - CrewAI Edition

## Visão Geral
Sistema educacional com IA para contexto brasileiro.

## Funcionalidades
- Currículos alinhados com BNCC
- Conteúdo em português brasileiro
- Preparação para ENEM
- Educação inclusiva
- Avaliações brasileiras

## Configuração
```bash
pip install -r requirements.txt
cp .env.example .env
python main.py
```
