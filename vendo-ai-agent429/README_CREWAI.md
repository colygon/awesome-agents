# Vendo AI - CrewAI Implementation

Multi-agent e-commerce AI platform for personalized recommendations, customer insights, and sales optimization.

## Agents

- **Product Specialist**: Recommendations, Q&A, product comparisons
- **Customer Insights Analyst**: Behavior analysis, preference prediction, segmentation
- **Sales Optimizer**: Pricing, promotions, upsells/cross-sells
- **Vendo Coordinator**: Integrated sales strategy and reporting

## Features

- Personalized product recommendations
- Customer behavior analysis
- Dynamic pricing optimization
- Promotional campaign creation
- Upsell/cross-sell suggestions
- Conversion optimization

## Installation

```bash
pip install -r requirements.txt
cp .env.example .env
```

## Usage

```bash
python main.py
```
