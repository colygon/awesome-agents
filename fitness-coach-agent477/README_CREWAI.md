# Fitness Coach - CrewAI Implementation

Multi-agent fitness coaching system with personalized workout programs, nutrition plans, progress tracking, and motivation support.

## Agents
- Personal Trainer: Workout program design
- Nutrition Coach: Meal planning and macro tracking
- Progress Tracker: Metrics analysis
- Motivation Coach: Accountability and goals

## Features
- Personalized workout programs
- Nutrition planning with calorie/macro tracking
- Progress monitoring and analysis
- Goal setting and motivation

## Usage
```bash
python main.py
```
