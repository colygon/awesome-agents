# Time Series Forecasting (Java) - CrewAI Edition

## Overview
Time series analysis and forecasting system. Original ADK was Java-based, this is Python CrewAI implementation.

## Agents
- Data Analyzer
- Forecasting Specialist (ARIMA, Prophet, LSTM)
- Anomaly Detector
- Validation Engineer
- Reporting Specialist

## Installation
```bash
cd time-series-forecasting-java-agent408
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Usage
```bash
python main.py "Monthly sales data" 60
```
