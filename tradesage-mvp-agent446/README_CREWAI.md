# TradeSage MVP - CrewAI Implementation

## Overview
An intelligent multi-agent trading system for market analysis, signal generation, and strategy development.

## Agents

### 1. Market Analysis Expert
- Analyzes market conditions
- Identifies trends and patterns
- Finds support/resistance levels

### 2. Technical Analysis Specialist
- Calculates technical indicators
- Generates trading signals
- Identifies chart patterns

### 3. Market Sentiment Analyst
- Analyzes news sentiment
- Tracks social media mood
- Gauges market positioning

### 4. Trading Strategy Designer
- Creates trading strategies
- Defines entry/exit rules
- Sets risk parameters

### 5. Backtesting Specialist
- Tests strategies on historical data
- Calculates performance metrics
- Validates strategy effectiveness

## Setup

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Configure environment:
```bash
cp .env.example .env
# Edit .env with your API keys
```

3. Run the system:
```bash
python main.py
```
