# CRM Q&A Agent - CrewAI Implementation

Multi-agent system for answering natural language questions about CRM data.

## Agents
1. **Query Interpreter** - Interprets user questions
2. **Data Retriever** - Retrieves CRM data
3. **Answer Synthesizer** - Synthesizes comprehensive answers

## Usage
```bash
pip install -r requirements.txt
python main.py
```
