# Project Manager Agent - CrewAI Edition

## Overview

Comprehensive AI-powered project management system that creates detailed project plans, work breakdown structures, resource allocations, risk analyses, schedules, and documentation.

## Features

1. **Project Planning** - Scope, objectives, stakeholders, methodology
2. **Task Breakdown** - Detailed WBS with 50-100 tasks
3. **Resource Allocation** - Team structure, assignments, budget
4. **Risk Analysis** - 25-30 risks with mitigation strategies
5. **Schedule Creation** - Milestones, Gantt charts, critical path
6. **Documentation** - Charter, communication plan, templates

## Output

- Project charter and scope definition
- Work Breakdown Structure (50-100 tasks)
- Resource allocation and budget breakdown
- Risk register with mitigation plans
- Detailed schedule with Gantt chart
- Project documentation package

## Setup

```bash
cd project-manager-agent414
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Add OPENAI_API_KEY to .env
```

## Usage

```bash
python main.py
```

Follow prompts for project details.

- New project initiation
- Project proposal development
- Resource planning
