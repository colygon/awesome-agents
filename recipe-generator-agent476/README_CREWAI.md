# Recipe Generator - CrewAI Implementation

A multi-agent system for creating recipes, meal plans, and nutritional analysis using CrewAI.

## Overview

This CrewAI implementation provides an intelligent recipe generation system with specialized agents for recipe creation, nutritional analysis, cooking instructions, and meal planning.

## Agents

1. **Recipe Creator**: Creates innovative recipes from available ingredients
2. **Nutritionist**: Analyzes nutritional content and optimizes for health
3. **Cooking Instructor**: Provides detailed cooking instructions and tips
4. **Meal Planner**: Creates balanced meal plans and shopping lists

## Features

- Recipe generation from available ingredients
- Nutritional analysis and calorie counting
- Dietary compliance checking (vegan, keto, gluten-free, etc.)
- Detailed cooking instructions with timing
- Recipe scaling for different servings
- Ingredient substitution suggestions
- Meal planning for any duration
- Shopping list generation
- Recipe variations and modifications

## Installation

```bash
pip install -r requirements.txt
cp .env.example .env
# Edit .env with your API keys
```

## Usage

```bash
python main.py
```

Choose between:
1. Single recipe generation
2. Meal plan creation

## Use Cases

- What's for dinner with available ingredients
- Weekly meal planning
- Dietary-specific recipes
- Cooking skill development
- Nutritional goal tracking
- Budget-friendly meal planning
